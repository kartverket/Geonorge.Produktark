# Produktarkgenerator

## **Beskrivelse av funksjonalitet:**

Tilbyr brukeren generering av produktark i pdf format for datasett. 

**Teknisk**

**URL**:

* **Dev:** [http://produktark.dev.geonorge.no/](http://produktark.dev.geonorge.no/ "http://produktark.dev.geonorge.no/")
* **Test:** [https://produktark.test.geonorge.no/](https://produktark.test.geonorge.no/ "https://produktark.test.geonorge.no/")
* **Prod:** [https://produktark.geonorge.no/](https://produktark.geonorge.no/ "https://produktark.geonorge.no/")
  

**Kildekode:** [https://github.com/kartverket/Geonorge.Produktark](https://github.com/kartverket/Geonorge.Produktark "https://github.com/kartverket/Geonorge.Produktark") 

**Oversikt kildekode**:

Applikasjonen er utviklet med C# og .NET framework.

* **/Kartverket.Produktark** Web applikasjon: ASP.NET MVC 5
* **/Kartverket.Produktark.Tests** Tester av applikasjonen
  

Benytter GPL Version av iTextSharp for å generere pdf.
