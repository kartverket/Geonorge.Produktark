# Geonorge.Produktark

Tilbyr brukeren generering av produktark i pdf format for datasett. 

## Kom i gang

### Forutsetninger

- .net framework 4.8

### Oppsett

1. Klon repoet:
   ```bash
   git clone git@github.com:kartverket/Geonorge.Produktark.git
   cd Geonorge.Produktark
   ```

2. Installer avhengigheter:
   ```bash
   yarn install
   ```
